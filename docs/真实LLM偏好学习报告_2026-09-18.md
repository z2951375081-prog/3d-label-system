# 真实 LLM 五视角偏好学习报告（2026-09-18）

本报告只记录项目真实执行产物；不将本地 mock 测试或未通过连接测试的请求算作实验结果。完整机器可读报告为 `experiments/llm_preference_run_8ff5edea-f390-4faa-b0c6-aa6b346ccfaa.json`。

## 实验配置

- 外部评分接口：OpenAI-compatible Chat Completions；报告只保存端点和模型，不保存 API Key。
- 评分模型：`gpt-5.6-luna`。
- 视觉输入：每个布局发送原始模型图，以及主、右、左、俯、仰五张带标签文字布局图，共 6 张实际渲染图片。
- train 样本：Chair/38635、Dishwasher/11898、Door/8944。
- 每个样本 2 轮、每轮 4 个不同 seed 的布局候选，共完成 24 次真实八维视觉评分。
- 非平局偏好：15 条，全部属于 manifest 的 train split，并绑定当前 `run_id=8ff5edea-f390-4faa-b0c6-aa6b346ccfaa`。
- 固定标签契约：chosen/rejected 在写入和离线训练时均复核标签数量、顺序、ID、原文、锚点、sourceObjs 和 targetGroups。
- GPT 八维分数：readability、coverage、occlusion、balance、binocular_consistency、size_consistency、group_economy、overall。
- 胜者规则：`0.6 × overall + 0.4 × 其余七维均值`；综合分差还用于成对梯度权重。

## 奖励网络

奖励模型为 `36→32→1` pairwise MLP。36 维输入由 16 个布局汇总特征，以及主/右/左/俯/仰每个视角的 OLR、LCD、越界和物体遮挡共 20 维组成。它只负责对多个退火候选重排，不直接修改基础布局 MLP。

训练使用 15 条本轮真实 LLM 偏好，人工偏好计数为 0；没有跳过非 train 样本、标签契约错误、来源错误、run_id 错误或无效评分凭据。训练 80 epoch、学习率 0.01、seed 17，最终 loss 为 0.753018，训练对准确率为 0.60。该准确率只是小样本训练拟合，不是泛化性能。

候选模型保存为 `experiments/preference_model_candidate.json`，SHA-256 为 `505A6CAC3C2C86AAB47B01CB179ECE9E29A327D366F7884590B9A90B9C0BEAB5`。

## val 门控与 test11

五视角能量越低越好：

| split | seed17 无奖励基线 | 奖励候选四候选重排 | 相对变化 |
| --- | ---: | ---: | ---: |
| val11 | 2.137273 | 2.211818 | 恶化 3.49% |
| test11 | 2.397545 | 2.317909 | 改善 3.32% |

val11 不满足“至少优于基线 1%”的预设门控，候选状态为 `rejected`。因此没有生成或替换活动 `preference_model.json`；test11 的改善不能反过来推翻 val 决策，也不能用来重新选择超参数。

test11 的部分指标为：

| 指标 | 无奖励 | 候选重排 |
| --- | ---: | ---: |
| OLR | 0.174818 | 0.161000 |
| LCD | 0.044909 | 0.034727 |
| 可读性代理分 | 4.306636 | 4.347000 |
| 物体遮挡比例 | 0.291545 | 0.262091 |
| 越界比例 | 0.024727 | 0.026636 |
| 五视角最差 OLR | 0.303636 | 0.327091 |
| 五视角最差越界 | 0.076000 | 0.086182 |

总能量、平均重叠和遮挡有所改善，但最差视角指标和越界指标变差，不能声称所有视觉维度都提升。数据量仅 3 个训练物体、15 条偏好，结论属于首轮可行性实验。
