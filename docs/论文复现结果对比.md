# 第一轮模型与 3D 标签论文复现结果对比

> 生成日期：2026-09-18。结果来自当前工作区的 Hedgehog、Plane、Baseline、MonocularForce、BinoForce 复现产物和本项目第一轮模型。

## 结论先行

- Hedgehog/Plane 在本地复现中重叠较低：全 55 个物体 × 5 视角时，Hedgehog 3D 的 OLR=0.02896，Plane=0.03465；但它们相对人工布局的 PCK@0.05 只有约 0.077–0.078，表示标签中心并不接近人工布局。
- BinoForce 在相同的 11 个 test 物体主视角中，相比 MonocularForce 的 OLR（0.06709 vs 0.06749）、LCD（0.01757 vs 0.02260）和 DBV（0.001586 vs 0.001628）都略低，但差距很小；本地复现并未表现出压倒性优势。
- 第一轮监督 MLP 的 test 回归 MSE=0.469486，优于训练目标均值基线 0.490035，约下降 4.19%。在本项目评价器中，配合“语义去重 + 双目退火 + 相对尺寸”，可读性代理从无模型的 4.4071 提升到 4.7582，OLR 从 0.1204 降至 0.0574，LCD 从 0.0209 降至 0；DBV 从 0.0165 略升到 0.0175。
- 第一轮不是所有条件都改善。“全部标签”条件的统一快照复评 OLR=0.40827，明显高于 BinoForce 最终主视角快照的 0.08627；说明当前模型必须配合标签选择/分组，下一轮应优先学习“哪些标签保留”，而非只优化中心位置。

规则式解码条件退化明显，不建议作为训练模型的主配置。当前推荐研究基线是“双目 + 语义去重 + 相对尺寸 + 退火”；固定尺寸虽然代理指标最好，但可能通过把标签做小而取巧，需要 GPT/人工评价可读性后才能定论。

建议论文最终对比统一为：相同 test 集、相同标签集合、相同标签尺寸、相同五视角相机、同一个评价器，并把动态方法按固定帧窗口评价；同时报告人工/GPT 盲评，而不是混用不同目录中的同名指标。
