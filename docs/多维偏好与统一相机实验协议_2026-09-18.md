# 多维偏好与统一相机实验协议

本报告记录项目内已经实现的评价、比较与实验协议，以及尚未满足的最终实验要求。结果以 experiments/comparisons/round1/comparison.json、experiments/llm_preference_convergence.json 和新的监督训练报告为准；历史旧报告不得直接用来推断新协议排名。

## 人工真值来源

人工基准来自 data/Layout/<category>/<sample>/layout1/Annotation/<sample>.json。55 个样本均声明 version=after_mannual_adjust、layout_type=manual_adjusted。最终 label.center、label.box_size 是监督目标，anchor.point、文本、标签 ID 和部件对应关系构成固定标签契约。

注意：活动 v2 网络的候选初始化仍使用人工最终 box_size；provenance-safe v4 的候选尺寸只由固定文本长度和干净几何计算，不能混称两者都无泄漏。新增训练使用后者，旧活动模型保持原文件，不擅自替换。

## 系统结构

```text
data OBJ → 清除既有标签/引导线 → 几何候选 + 固定标签契约
                                      ↓
              51维特征 → 四专家MLP → 6维位置/尺寸参数
                                      ↓
                      五视角联合退火 → 多个布局候选
                                      ↓
             750×500五视角文字图 + 几何指标 + 人工最终参考
                                      ↓
                         外部视觉LLM十二维评分
                                      ↓
                     train偏好对 → 49→32→1奖励MLP
                                      ↓
                         val轮次选择/激活门控
                                      ↓
                         最终选定候选 → test评估
```

神经网络构成：

- 布局网络：四个风格专家（balanced、elongated、dense、symmetric），每个为 51→128→64→32→6，隐藏层 tanh，输出层 linear。门控为确定性的几何风格规则，不是另外一个学习网络。
- 51维输入：16维三维几何/候选属性，五视角各7维投影属性。v4输入不能读取人工调整后的中心或框尺寸。
- 6维输出：相对于固定锚点的三维位置偏移与三维框尺寸，按物体半径归一化。
- 监督损失：默认 0.65×三维参数MSE + 0.35×五视角中心/面板宽高MSE。新训练中输入投影、监督投影、评价和预设渲染使用同一相机协议。
- 奖励网络：新增训练为49→32→1，使用pairwise logistic loss；在原45维多视角、文字、遮挡和深度穿模特征尾部追加网格表面相交、候选自身的空间平衡、尺寸一致性及不含人工真值的综合分。历史36/45维候选保持兼容。人工最终中心/风格仍参与LLM的评分与独立评估，但绝不作为奖励网络的推理输入；GPT分数也不是推理输入。

- 在线多轮实验先按每轮累计偏好训练，再以val联合门控保存独立模型快照和SHA-256；最终只对val分数最高的已接受轮次运行一次test。若所有轮次均被拒绝，仅用val分数最高的被拒轮次生成诊断性test报告，不将其激活。test不参与选轮；人工位置/风格进入LLM评分和最终指标，但不能进入测试时的奖励网络输入。

上述结构是本项目小数据量条件下的可训练工程设计，并非某篇论文证明的唯一最佳结构；没有把未实现的CNN/GNN/Transformer当作已经完成的训练网络。

## 相机证据与公平比较

共享代码：public/dataset-camera.js；来源协议：experiments/dataset_camera_protocol.json。

- data直接证据：750×500图片、main/right/left/up/down视角名。
- 两套复现共同参数：50mm焦距、36×24mm传感器、距离10、主方向[1,1,1]、左右/上下沿屏幕轴偏转45度。
- data未提供原始相机矩阵、FOV或焦距；上述数值已受到PNG中红色引导线的图像反推支持，但仍不能称为已找回的数据集原相机元数据。恢复原始导出脚本仍是独立任务。
- 图像标定脚本：`py -3 scripts/calibrate-dataset-camera.py --views main,right,left,up,down --train-limit 12 --maxiter 6`，报告：`experiments/dataset_camera_calibration.json`。每个视角仅用12个train样本中的人工最终3D引导线及红线像素拟合，val11/test11只用来验算；距离10固定，不声称焦距与距离已独立识别。
- 原50mm/36×24mm共享协议在独立test11上的红线对齐误差（px，越低越好）：main 1.266、right 1.066、left 1.097、up 1.215、down 1.202。拟合方向与原协议差异最大0.084°，主视角估计等效焦距约49.77/49.83mm，右视角初始值本身已优于拟合器的其它候选，保留原值。拟合后的test11误差分别为1.170、1.066、0.982、1.110、1.106px。因差异很小，未改动统一相机参数或既有比较；数值仅支持协议与数据图像吻合，不证明其物理元数据真实存在。
- 固定预设截图已改为750×500，不随页面CSS尺寸或设备像素比变化。自由拖拽视图用于交互，不代表统一实验相机。
- 当前比较使用test11、固定标签契约、共享五视角、同一个评价器。人工尺寸来源不同仍须报告。
- 历史round1_mlp_all标签契约不一致，仅诊断展示，不进入排名。current_fixed_label_seed17是重新生成的固定标签推理行；它使用保留的旧活动网络，网络与新投影的训练匹配尚须用新候选验证。
- BinoForce_final_snapshot是最终快照，不是300帧动态均值；原CSV指标单独保留，不能混进静态统一表。

## 独立指标

| 字段 | 含义与方向 | 证据级别 |
| --- | --- | --- |
| label_label_occlusion_ratio | 标签框重叠面积比，越低越好 | 投影矩形度量 |
| label_object_occlusion_ratio | 标签在物体前方遮挡的采样比例，越低越好 | 深度栅格代理 |
| object_label_occlusion_ratio | 物体在标签前方遮挡的采样比例，越低越好 | 深度栅格代理 |
| object_penetration_ratio | 标签深度落入物体前/后表面深度区间的采样比例，越低越好 | 不能视为精确体积碰撞 |
| mesh_surface_intersection_ratio | 五视角标签盒与物体三角形真实表面相交的标签比例 | 三角形/OBB分离轴检测，不含完全包围却无表面接触的盒 |
| text_pixel_height | 当前兼容字段实际是投影面板高度，不是字形实际字号 | 需要后续Canvas测量替代，不能冒充OCR/字体测量真值 |
| text_fit_ratio | 按字符数与估算字符宽度得到的面板容纳比，越高越好 | 不含实际字形、折行测量 |
| text_clipping_ratio | 面板越界代理，越低越好 | 几何裁切，不等价于字形裁切 |
| lcd | 引导线交叉对比例，越低越好 | 直线投影度量 |
| manual_center_distance_norm | 按标签ID对应的人工最终中心距离/物体半径，越低越好 | 人工JSON数值距离 |
| manual_style_distance | 引导线长度/离散度、径向分布/离散度、空间平衡与尺寸距离均值 | 显式工程风格距离，越低越好 |

multidimensional_quality_score是确定性代理综合分，不是LLM评分。人工位置与风格共占20%；其余为文字、覆盖、遮挡、深度穿模、三角网格表面相交、引导线与多视角稳定项。人工参考或精确网格缺失时剔除相应项并重新归一化，不能把缺失值当0。不同标签契约的历史行不允许综合排名。

## 外部LLM十二维评分

评分Schema：experiments/score-schema.json。维度为text_clarity、coverage、label_label_occlusion、object_occlusion、object_penetration、leader_line_clarity、multiview_consistency、binocular_consistency、manual_style_similarity、spatial_balance、size_consistency、overall。全部1–5分，5最好。

偏好复合分：0.35×overall + 0.15×manual_style_similarity + 0.50×其余十个约束维度的均值。浏览器候选排名与训练脚本共享public/preference-scoring.js定义。归一化分差加权pairwise梯度，权重为1+2×分差。

服务端对数据集候选重算几何并读取人工最终JSON，作为authoritative_geometry_metrics与authoritative_manual_reference发送给LLM，不依赖客户端自报的人工距离。标签集合固定，禁止建议删减、合并或改名。评分凭据绑定原候选、策略与分数；连接探针不签发train凭据。

旧八维评分默认不用于新十二维训练。历史分析须显式--allowLegacy，保持原八维复合公式，不伪造未评过的穿模和人工风格分。

## 多轮分析与当前边界

脚本：scripts/analyze-preference-convergence.mjs；运行命令：npm run analyze:preference-convergence。默认检查0/1/2/4/8轮，只累计train偏好，固定val11候选选择轮次，最后才评test11。当前脚本是已有偏好记录的复算分析，不等价于每轮都用新优化模型重新生成并由LLM重评分的在线闭环。

现有真实run 8ff5edea-f390-4faa-b0c6-aa6b346ccfaa仅包含2轮旧八维评分。报告会把4/8轮标记unavailable。它不是十二维评分与新相机截图下的收敛证据。局部变化小于0.02只能称为初步平稳；至少需1/2/4三个真实训练检查点，且质量超过0轮基线，才允许宣称正向收敛。

当前在线闭环已修正为“全体样本按轮次收集→每轮累计训练→val联合门控→独立模型快照与SHA-256→所有轮次结束后由val选择最佳已接受轮次→仅运行一次test11”。如果所有轮次均被拒绝，只选择val分数最高的被拒轮次产生诊断性test报告，不激活模型。奖励网络的49维推理输入已通过测试证明不随人工最终中心/风格的删除或篡改而变化；人工结果只用于LLM监督、val/test独立指标和最终报告，避免测试真值泄漏。
