# v10 锚点局部坐标异构图与多视角安全训练（2026-09-21）

## 目标架构

当前 v10 基础生成器采用以下纯三维路径：

~~~text
clean OBJ → 1024 点 → 2×EdgeConv → 64D OBJ 几何
                                      ↓
锚点表面 patch → 加权 PCA / 法向平均 → (t1,t2,n)
                                      ↓
                         51D 局部三维标签特征
                                      ↓
                         51→64→128→64 残差 FNN
                                      ↓
      anchor→label 18D + label→label 10D 关系类型感知异构图
                                      ↓
                         2 层关系 GNN（独立关系参数）
                                      ↓
                         1 层全局 Transformer
                                      ↓
                         人类风格 Softmax MoE
                                      ↓
                         64→32→6 局部坐标解码
~~~

五视角图像、深度栅格和本地 Qwen 均不进入初始三维坐标生成器。五视角只用于可微近似安全损失、确定性模拟退火、安全门控和结果评价；Qwen 只对已经通过确定性安全筛选的候选进行美学排序。

## 锚点局部坐标系

每个锚点从 clean OBJ 三角形中选取局部 patch。三角形按面积和锚点距离加权，法向先做同向对齐后再平均；PCA 第一主方向投影到切平面得到 `t1`，`t2 = n × t1`。`t1` 使用物体中心到锚点的切向投影做符号对齐。

实现包含以下退化处理：

- 法向稳定度低、曲率高或 patch 三角形太少时，最多两次扩大 patch；
- 尖角处使用多个三角形的面积/距离加权法向；
- 零面积三角形不进入 patch；
- PCA 退化时使用与法向不平行的世界轴作为切向回退；
- 默认记录 `(t1,t2)` 与 `(-t1,-t2)` 两个等价方向，供对称物体审计和后续最小损失匹配扩展。

## 异构关系图

图中有固定 anchor 几何节点和可更新 label 节点。所有 anchor 连接到所有 label，因此“共享 source object / target group”不是恒定值。

anchor→label 的 18 维特征：

- 标签相对该锚点局部框架的 `u,v,normal-distance`；
- 锚点法向；
- 锚点到标签的引导线方向与距离；
- 引导线和法向夹角；
- 局部表面曲率与 patch 尺度；
- 标签三轴尺寸；
- 是否共享 source object；
- 是否属于同一 target group。

label→label 的 10 维特征：

- 三维相对位置与距离；
- 三轴尺寸对数比例；
- 相对方向夹角余弦；
- 是否共享 source object；
- 是否属于同一 target group。

每层关系 GNN 使用独立的 `anchor_edge_weights` 和 `relation_edge_weights`。anchor 消息和 label 消息分别聚合后注入目标 label，避免把两种关系简单拼接成一个不可区分的边向量。

## 五视角安全目标

主、右、左、俯、仰视角权重分别为 `0.40, 0.15, 0.15, 0.15, 0.15`。逐视角计算：

- 标签区域与物体 silhouette 的交叠比例；
- 标签位于物体后方的深度遮挡比例；
- 标签深度落入物体前后表面区间的穿模比例；
- 标签—标签交叠与视野越界；
- 两两引导线投影交叉比例与平滑交叉风险（加权均值、最差视角和 CVaR）；
- 字体像素高度、宽度容纳度和裁切代理；
- 标签方向分布与当前视角空闲区域分布的失配；
- 左右视角分布一致性。

总目标同时包含加权均值、最差视角和 CVaR。最差深度遮挡、最差穿模和引导线交叉不能被其他视角的低损失平均掉。训练中还单独加入引导线方向余弦损失和逐视角字体清晰度损失。引导线交叉使用连续风险代理通过有限差分进入基础网络梯度，同时保留投影线段真实相交计数用于评估；模拟退火继续用真实交叉计数做安全优化。val11 激活门控要求引导线交叉比例相对旧活动模型最多增加 0.005。

原来的“全局方向越均匀越好”不再进入 v10 三维风格损失；方向分配改由每个视角的 `free_space_distribution_mismatch` 驱动，使标签优先占用实际可用留白，而不是机械追求八方向等数量。

## 训练、选择和激活

~~~powershell
npm run test:anchor-view
npm run train:layout:v10 -- --epochs 80 --learningRate 0.002 --directionWeight 1.25 --viewWeight 0.25 --worstViewWeight 2 --cvarViewWeight 1 --stereoWeight 1 --textClarityWeight 3 --leaderCrossingWeight 3.5 --expertCount 4 --seed 17
npm run select:layout:v10 -- --previous experiments/layout_model.json
npm run activate:layout:v10
~~~

训练只使用 train33 更新参数，val11 选择检查点和推理混合比例，test11 只作最终确认。激活脚本校验 51D 节点输入、18D/10D 两类关系参数、两层消息传递、一层 Transformer、MoE、局部 6D 解码和各参数组的真实更新，并在替换活动模型前保留旧模型和哈希记录。

长训练每满十分钟输出一次进度 JSON，避免高频轮询。训练完成后再更新网页活动模型、五视角结果、质量表和 Qwen 安全候选重排实验。
