# 最终 FNN 四专家布局模型与本地 Qwen 偏好训练报告（2026-09-20）

## 最终活动模型

布局模型版本为 `layout_model_v7_fnn_relational_graph_transformer_moe`，结构为：

~~~text
51D 节点特征
→ 51→64 节点编码
→ 64→128→64 前置残差 FNN
→ 2 层关系 GNN（13D 边特征）
→ 1 层全局 Transformer（64→128→64 FFN）
→ 4 专家 Softmax MoE
→ 64→32→6 输出
→ 五视角安全优化与模拟退火
~~~

四个专家分别为 `geometry`、`relations`、`multiview_style`、`global_context`。验证集平均路由权重分别为 31.8945%、31.8945%、31.8945%、4.3165%，全部专家均获得非零路由。

布局模型使用 train33 更新，val11 选择检查点和推理融合比例，test11 只作最终确认。固定标签契约审计覆盖 55 个样本和 406 个标签，数量、顺序、ID、文字、锚点、`sourceObjs`、`targetGroups` 均通过。

## 前置 FNN 的实际作用证据

最终候选训练 5 轮，最佳检查点为第 5 轮。前置 FNN 有 16,576 个参数，其中 16,572 个相对初始化发生变化。只看参数变化不足以证明模块生效，因此训练器增加了验证集消融：保留其余权重不变，仅移除前置 FNN，再比较六维网络输出。

- 最大绝对输出差异：`3.679111210126316e-6`
- RMS 输出差异：`1.6417791450528724e-6`
- 验证节点：80
- 比较输出值：480

激活门禁要求该最大差异大于 `1e-8`。最终模型满足要求，证明 FNN 不只是结构声明，而是实际参与推理。

## 边界与解释

- 布局 v7 的验证和测试指标相对 v6 为非退化，而不是显著提升；其主要成果是增加了有可观测功能证据的前置 FNN 和第四专家。
- 当前真实 Qwen 偏好训练只有一个 train 样本、两对偏好，足以证明端到端机制和本轮门禁结果，但不代表广泛类别上的奖励泛化已经充分建立。
- 视觉验证中的 Qwen 评分出现高分饱和，因此最终激活仍由完整 val11 的确定性美学代理和几何安全门禁控制。
- 奖励模型只在安全候选中重排，不能绕过五视角几何安全约束，也不直接修改基础布局网络权重。
