## 真实 LLM 轮的验收条件

以下证据全部出现后，才可把“真实外部 LLM 偏好学习”标记为完成：

1. 网页连接状态显示六图/JSON 自检通过，并记录 `testedAt`。
2. `experiments/preferences.jsonl` 中存在同一 `run_id` 的 `llm_pairwise_preference`，全部属于 manifest train 样本。
3. 每条记录有两个不同的服务端 receipt ID、同一评分模型、固定标签契约通过，且没有 Key 或图片数据落盘。
4. `experiments/preference_model_candidate.json` 的 `training.source_filter` 为 `llm`、`run_id_filter` 等于本轮 ID、`source_counts.human` 为 0；只有通过 val 时才允许出现或替换活动 `preference_model.json`。
5. `experiments/preference_test11_report.json` 是本轮奖励模型生成的 test11 对照，不把 test 数据写回训练。
6. `experiments/preference_validation_selection.json` 证明候选奖励模型只由 val 决定是否激活；拒绝候选未覆盖活动模型。
7. `experiments/llm_preference_run_<run_id>.json` 与 `experiments/llm_preference_run_latest.json` 存在，记录评分模型、receipt/response ID、偏好对数量、奖励模型训练摘要、val 门控及 test11 结果，且不包含 API Key。

## 当前安全边界

- 不复述、不保存、不复用曾在聊天中暴露的 Key。
- API Key 在写入服务内存和构造 Authorization Header 前必须是纯可打印 ASCII Token；包含中文、内部空格、换行、`Bearer ` 前缀或异常长度时会直接返回 400，并且不会向外部端点发送请求。该校验已通过单元测试和正式服务本地请求验证。
- 同样拒绝带引号/反引号以及 `api_key=`、`Token:`、`Authorization:` 等说明前缀的误粘贴内容。每次真正执行六图连接测试时，会向 `experiments/scoring_connection_attempts.jsonl` 追加不含 Key、Authorization、图片和原始响应的安全审计记录，用于区分认证失败、结构化 JSON 失败及传输失败；仅保存连接配置而未发出六图测试时不写审计记录。
- 更换 URL、模型或 Key 后会清除六图自检状态。
- 未通过自检不签发训练凭据，不允许自动偏好轮。
- 自动 LLM 训练只读取当前 `run_id` 的真实 LLM train 偏好，不混入人工 A/B 或历史运行。
- 模拟接口测试只证明程序协议链路，不能替代真实第三方模型实验。
